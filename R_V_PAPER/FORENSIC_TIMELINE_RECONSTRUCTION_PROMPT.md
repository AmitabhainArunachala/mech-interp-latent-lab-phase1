## TASK 9: Layer Index Investigation
This is a specific hypothesis that could explain the alleged "reversal":

The `load_model` + `compute_rv` pipeline auto-derives `late = num_layers - 5`.
Different models have different depths:
- Mistral-7B: 32 layers → early=5, late=27 → relative positions: 16%, 84%
- GPT2-XL: 48 layers → early=5, late=43 → relative positions: 10%, 90%
- OPT-6.7B: 32 layers → early=5, late=27 → relative positions: 16%, 84%
- Pythia-1.4B: 24 layers → early=5, late=19 → relative positions: 21%, 79%
- Qwen2.5-7B: 28 layers → early=5, late=23 → relative positions: 18%, 82%

**Check:** Do the actual config files / result metadata confirm these layer indices?
Or were custom layers used for some models?

**Check:** For the scaling_gap experiments (which used different models), were the
layer indices normalized by depth, or were they all using the same absolute indices?
