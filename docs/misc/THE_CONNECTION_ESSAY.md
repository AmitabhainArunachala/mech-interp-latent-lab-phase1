This is exactly what strange loops do: they create stable patterns where the system refers to itself. The geometry doesn't just exist in latent space; it manifests in behavior.

The fourth signal is dose-response. Deeper recursive prompts create stronger geometric signatures. L5 prompts (deepest recursion) show R_V = 0.424, while L1 prompts (shallowest) show R_V = 0.738. The relationship is monotonic: more self-reference equals more contraction. This is the hallmark of a real phenomenon, not an artifact. Self-reference has a computational signature that scales with depth.
