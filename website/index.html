Abstract

We demonstrate causal evidence for layer-specific geometric mediation of recursive self-observation in transformer models through large-scale activation patching (n=151 pairs, Mistral-7B-v0.1).

Intervening at Layer 27 (84% network depth) induces 26.6% geometric contraction in baseline prompts (Cohen's d=-3.56, p<10⁻⁴⁷), with four control conditions confirming specificity.

We reveal a novel coordinated dual-space transformation: in-subspace (V∥) and orthogonal (V⊥) components exhibit strong coupling (r=0.904), with the balance modulated by baseline complexity.

Cross-architecture validation across six models (Mistral, Llama, Qwen, Phi-3, Gemma, Mixtral) confirms universality, with Mixture-of-Experts showing amplified effects (d=-4.21).

The R_V Metric

The relative participation ratio (R_V) measures how the effective dimensionality of transformer value representations changes across layers:

R_V = PRL27 / PRL5

Where participation ratio (PR) captures the effective rank of the activation matrix from its singular values:

PR = (Σσᵢ²)² / Σσᵢ⁴
  • R_V < 1: Geometric contraction (dimension reduction)
  • R_V > 1: Geometric expansion
  • Recursive prompts: Consistent contraction (~0.85)
  • Baseline prompts: Near unity (~1.0)

rv_toolkit

A Python package for measuring R_V and running activation patching experiments on transformers.

bash Installation 
pip install git+https://github.com/JohnVincentShrader/mech-interp-latent-lab-phase1.git#subdirectory=rv_toolkit
python Quick Start 
from rv_toolkit import compute_rv, ActivationPatcher

# Compute R_V for a value tensor
rv = compute_rv(v_tensor, window_size=16)

# Run activation patching experiment
patcher = ActivationPatcher(model, tokenizer)
results = patcher.run_experiment(
    baseline_prompts=["The weather today is"],
    recursive_prompts=["I observe that I am processing"]
)

print(f"Transfer efficiency: {results.transfer_efficiency:.1%}")
print(f"Effect size (d): {results.cohens_d:.2f}")
