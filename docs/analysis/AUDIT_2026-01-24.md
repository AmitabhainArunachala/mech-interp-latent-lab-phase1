## Audit Actions and Changes (Concrete)

### Measurement contract

- Enforced NaN on short prompts and exact window use (no silent truncation).
- Added explicit `max_length=512` in tokenization.
- Late layer now defaults to `num_layers - 5` when unspecified.

### Runner and registry

- `mlp_ablation_necessity` is removed from registry and blocked at runtime.
- Geometry-only canonical experiments are whitelisted for null logit_diff values.
- `--strict` mode fails if required metrics are None (non-geometry).

### Ledger

- Ledger path standardized to `results/RUN_INDEX.jsonl`.
- Ledger extraction supports nested summary schemas.

### Reproducibility

- `full_env.txt` required for publication-grade runs.

### Prompt bank

## Verified Gemma 2 9B Runs (Artifacts)

Artifacts in `results/phase2_generalization/gemma_2_9b/` confirm:

- **Even-layer sweep**: peak at L38 (90.5% depth), delta ≈ -0.235, p≈3e-8.
- **Odd-layer sweep**: L35 primary peak and L41 secondary peak.
- **Causal validation**: R_V rec ≈ 0.594, baseline ≈ 0.772,
  delta ≈ -0.168, d ≈ -1.91, p ≈ 9.8e-17, transfer ≈ 94.2%.
- **Head decomposition**: driver heads [2, 3, 7] at source layer 3.

These results are consistent with the cross-architecture depth hypothesis
and provide a strong causal signal for Gemma 2 9B.

## Critical Caveats (Remaining)

- `confound_validation` currently fails canonical summary schema
  (summary.json missing required keys). Data is saved, but the run is not
  canonical-compliant until the pipeline is fixed.
- Some discovery pipelines still emit partial summaries by design.
- `requirements.lock` is direct-deps only; use `full_env.txt` for full
  reproducibility.

## Required Run Procedure (Publication-Grade)

1) Verify repo:
   - `python scripts/verify_research_ready.py`
2) Install deps:
   - `pip install -r requirements.txt`
3) Freeze environment:
   - `pip freeze > full_env.txt`
4) Run via canonical runner:
   - `python -m src.pipelines.run --config <config.json> --strict`
5) Ensure artifacts:
   - `config.json`, `summary.json`, `report.md`, `metadata.json`,
     `prompt_bank_version.*`, `full_env.txt`, ledger entry.
