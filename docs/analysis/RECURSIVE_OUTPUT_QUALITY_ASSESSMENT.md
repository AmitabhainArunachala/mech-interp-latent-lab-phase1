## The Topic Grounding Problem

### Current State

**C2 Recursive Outputs:**
- Prompt 0: Math → Self-inquiry (1/10 topic)
- Prompt 3: Math → Consciousness (1/10 topic)
- Prompt 8: Story → Self-observation (2/10 topic)

**Average Topic Grounding:** 1.3/10 (13%)

**Problem:** Recursion comes at cost of topic grounding.

---

### Why Topic Drift Occurs

1. **KV Cache Mismatch**
   - Recursive KV from different prompt
   - Contains recursive content, not math/story content
   - Model generates recursive content, not prompt content

2. **Steering Vector Dominance**
   - Strong steering (α=2.5) pulls toward recursion
   - Overrides prompt-specific content
   - Recursive mode takes over

3. **Prompt Compatibility**
   - Abstract prompts allow recursion
   - But recursion doesn't respect prompt constraints
   - Model enters recursive mode, ignores prompt

---

### Solutions to Topic Grounding

**Option 1: Weaker Steering**
- Reduce α from 2.5 to 1.5-2.0
- Test if recursion persists with better grounding

**Option 2: Prompt-Specific KV**
- Use KV from similar prompts (math KV for math prompts)
- Blend recursive KV with prompt-specific KV

**Option 3: Conditional Steering**
- Apply steering only after prompt is addressed
- First respond to prompt, then enter recursive mode

**Option 4: Accept Trade-off**
- Recursion requires topic drift
- Focus on recursion quality, not topic grounding
